# Contributing to Silkroad Developer Community (SDC)

Thank you for your interest in contributing! We're building a vibrant, open-source community for the Silkroad Online developer ecosystem.

## How to Contribute

Whether it's bug fixes, new features, or documentation improvements, we welcome all types of contributions.

1. **Check the Projects**: Look at our repositories for open issues or create them.
2. **Read the Governance**: Our community's rules, membership, and decision-making processes are detailed in the [GOVERNANCE](https://github.com/Silkroad-Developer-Community/GOVERNANCE) repository.
3. **Join Discord**: Many discussions happen in real-time on our [Discord Server](https://discord.gg/FEmNcz7QwP).
4. **Follow the Code of Conduct**: All contributors are expected to adhere to our [Code of Conduct](https://github.com/Silkroad-Developer-Community/.github/blob/main/CODE_OF_CONDUCT.md).

## Membership

If you're interested in becoming a long-term member and having more influence in the community, please check out the [Membership Application](https://github.com/Silkroad-Developer-Community/GOVERNANCE/issues/new?template=APPLICATION.yml) in the GOVERNANCE repo.

## Pull Requests

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Submit a Pull Request.
4. Provide a clear description of your changes.

Thanks for building with us!
