# Support for SDC

Need help with an SDC project? We're here to help!

## SDC Discord Server

Our Discord server is the best place for real-time support and community discussions. It's safe to ask questions, share your progress, and get help from our members.

- **Join Discord**: [Invite Link](https://discord.gg/FEmNcz7QwP)

## GitHub Issues

For bug reports or feature requests, please use the issue tracker for the specific repository they relate to. This helps us track and manage fixes effectively.

## Reporting Security Issues

If you've found a security vulnerability, please check our [Security Policy](https://github.com/Silkroad-Developer-Community/.github/blob/main/SECURITY.md) for reporting instructions.

Thanks for being part of the SDC!
